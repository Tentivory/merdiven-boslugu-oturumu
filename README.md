# Merdiven Boşluğu Oturumu

Resmî adıyla **Apartman İçi Yankı Meclisi, Kat 0 – Çatı Arası**. Gayriresmî adıyla: komşunun terliği yankılanınca başlayan, hiçbir şeye karar veremeyen ciddi toplantı.

Bu depo bir şakadır. Ama çalışır. Merdiven boşluğu da öyle: herkes konuşur, kimse inmez.

## Ne işe yarar

`oturum.py` bir oturum açar. Katlar söz alır. Çoğunluk gelmez. Gündem maddesi “lampayı kim değiştirecek” diye başlar, “yankı yeter sayı mı” diye biter. Çıktı Türkçedir. Karar çıkmaz. Bu bir özelliktir, hata değil.

## Kurulum

Python 3 yeter. Bağımlılık yok. Komşu izni de yok.

```bash
python oturum.py
python oturum.py --kat 7 --gundem "asansor yine duygusal"
python oturum.py --tutanak
```

## Bilimsel dayanak

1. Ses yukarı çıkar.
2. Karar aşağı inmez.
3. Zemin kat her zaman geç kalır çünkü kapıyı tutuyordur.
4. Çatı katı yeter sayıya dahil değildir; orası depo, meclis değil. Depo olduğu için bu depodadır.
